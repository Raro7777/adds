# 광고채널 성과 대시보드 — 프로토타입 (v0.1)

스펙 v6.3 검토 문서(`spec-review-v6.3.md`)를 기반으로 만든 정적 프로토타입.
빌드 도구 없이 브라우저에서 바로 열어 동작 확인이 가능합니다.

## 실행

```bash
# 옵션 1: 파일 직접 열기
open index.html

# 옵션 2: 로컬 서버 (권장 — 일부 브라우저는 file:// 에서 차트 폰트 경고)
python3 -m http.server 8000
# → http://localhost:8000
```

## 구성

```
index.html              # 3탭 셸 (대시보드 / 광고비 설정 / 팀·상담원)
assets/
  app.js                # 탭 전환, 집계, 렌더 로직
  mock-data.js          # 채널 7개 · 팀 3개 · 상담원 11명 · 14일치 인입
  styles.css            # 보조 스타일
```

## 반영 사항

### 확정 (v7.0 예정)
- **미매핑 상담원**: 알림 표시 → 운영자 등록 시 자동 반영 (§4-2)
- **팀별 광고비 배분**: 인입 비율 배분 — `팀 광고비 = 팀 인입수 × (채널 광고비 ÷ 채널 총 인입)` (§4-1)
- **이름 정규화**: 앞뒤 공백 자동 trim (§4-1)

### UI에 표시되는 미확정 항목
- 타입 B 소급 처리 (§3-3-1 ↔ §3-5 충돌) — 광고비 설정 탭에 경고 표시
- 부가세/수수료 미적용 방식 — 토글로 시뮬레이션
- 중간 공백 trim 정책 (#4-a) — 힌트 텍스트로 표기
